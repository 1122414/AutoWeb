# 操作 iiice 资源混合页

## 识别页面

- 区分顶部可切换搜索引擎的输入框与下方密集资源卡片。
- 按卡片可见名称和所在分区联合匹配；不要把图片 CDN 地址当成目标平台。
- 将脚本新标签、二维码、联盟页和 App 唤起视为不同的跳转结果。

## 执行

1. 优先精确匹配卡片名称。
2. 找不到入口时使用顶部搜索框，并在查询中限定目标官方域名。
3. 点击后读取最新标签页及最终 URL，记录完整重定向链。
4. 遇到二维码或 App 门槛时保存证据并安全停止。
