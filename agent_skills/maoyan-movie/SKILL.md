# 操作猫眼电影页面

- 识别红色猫眼标识、城市、电影或影院导航、搜索框和电影卡片。
- 按片名精确搜索，并用年份、主创或上映信息排除同名作品。
- 依次核对日期、影院、场次、语言版本和票价。
- 进入座位图后按银幕方向和行列理解可选座，不自动选择真实座位。
- 只到座位或订单确认预览，在确认购票、提交订单或支付之前停止。
- 遇到 403、验证码、登录或 App 唤起时停止，不绕过。
