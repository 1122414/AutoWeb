# 核验 GitHub 仓库与官方外链

1. 使用完整的 `owner/repo` 标识仓库，避免相似名称。
2. 区分 Trending 条目、仓库 README、About/Homepage 和 Releases。
3. 只信任仓库 About 或 README 明示的官方项目域名。
4. 打开外部演示后核验最终域名，只执行只读验证。
5. 不注册、不创建资源，也不提交 Issue、PR、评论或消息。
